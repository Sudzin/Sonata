# ROADMAP (План разработки)

Здесь мы фиксируем все идеи, баги и предложения по улучшению плеера Sonata, чтобы ничего не потерялось.

## 1. Вкладка Альбомы (Albums)
- [ ] Полноценный апгрейд вкладки (создание, ручное редактирование альбомов).
- [ ] Возможность менять местами элементы (Drag & Drop).
- [ ] Закрепление любимых альбомов (Pin/Favorites).
- [ ] Подтянуть локализацию (исправить "1 track" без изменения оригинальных названий и артистов).

## 2. Эквалайзер (EqView)
- [ ] Сохранение пресетов эквалайзера индивидуально для каждого трека.
- [ ] Исправление визуальных багов (просвечивание блоков на фоне).
- [ ] Починить вкладку "Свой" (Custom), чтобы пользователь мог настраивать ползунки и сохранять свой пресет.
- [ ] Добавить инфографику/интерактивный график изменения частот (визуализация EQ).

## 3. Нижняя панель (PlayerBar)
- [x] Убрать бонусную шестеренку (уже есть в профиле).
- [x] Сделать блок выше, отцентровать и выровнять все элементы по одной линии.
- [x] Увеличить иконки кнопок повтора и перемешивания.
- [x] Добавить сохранение уровня громкости между запусками приложения.
- [x] Починить логику переключения режимов повтора (один трек, все, без повтора).

## 4. Статистика (StatsView)
- [ ] Переработать дизайн карточек (убрать "разноцветное чудо", сделать в едином стиле приложения).
- [ ] Исправить визуальные баги (просвечивание фона за контейнерами).
- [ ] Расширить наполнение контейнера со статистикой (добавить больше интересных метрик прослушивания).
